プライバシーポリシー

制定日：2026年11月23日

コツコツ工房（以下「開発者」）は、Android アプリ「イエカルテ - 家のメンテ台帳」（以下「本アプリ」）における利用者の情報の取り扱いについて、次のとおり定めます。

1. 取得する情報

本アプリは、利用者が入力した次の情報を、お使いの端末の中にだけ保存します。

  • 家電の名前、種類、メーカー、型番
  • 購入日、保証期限
  • メモ（消耗品の型番など）
  • お手入れ項目、周期、作業日、完了日
  • 通知する時刻などの設定

本アプリは、氏名、メールアドレス、電話番号、位置情報、連絡先、広告 ID などの個人を特定できる情報を取得しません。アカウント登録もありません。

入力した情報は端末内のアプリ専用の領域に保存され、ほかのアプリからは読めません。

2. カメラと文字の読み取り

型番ラベルの撮影には、端末のカメラアプリを使います。撮影した写真は、Google ML Kit の文字認識（端末内で処理するモデル）で文字を読み取るためだけに使い、読み取り後すぐに削除します。写真や読み取った文字を外部に送信することはありません。

3. 外部への送信

本アプリは、利用者が入力した情報や撮影した写真を、開発者や第三者のサーバーへ送信しません。開発者が運営するサーバーはなく、アクセス解析、広告、クラッシュレポートの仕組みも組み込んでいません。

ただし、文字の読み取りに使う Google ML Kit は、Google の利用規約に基づき、機能の改善のために API の動作状況や利用状況に関する統計情報（端末の種類、処理時間など。写真や読み取った文字は含みません）を Google に送信することがあります。詳しくは Google の説明をご覧ください：https://developers.google.com/ml-kit/terms

4. 通知

お手入れの日をお知らせするため、端末のローカル通知を使います。通知の予約は端末の中で行い、外部のサーバーは使いません。通知は端末の設定からいつでもオフにできます。

5. 情報の削除

本アプリ内で家電を削除すると、その家電の記録と通知の予約も削除されます。本アプリをアンインストールすると、端末に保存したすべての情報が削除されます。開発者は利用者の情報を保有していないため、開発者側で削除や開示に応じる対象となる情報はありません。

6. 端末のバックアップ

Android の端末バックアップ機能が有効な場合、本アプリのデータが利用者自身の Google アカウントのバックアップに含まれることがあります。これは Android の機能によるもので、開発者がその内容を見ることはできません。

7. 子どもの利用

本アプリは、子どもから意図して情報を集めることはありません。

8. このポリシーの変更

内容を変更する場合は、本ページを更新し、アプリの更新とあわせてお知らせします。
